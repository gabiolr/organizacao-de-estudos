Descrição
 Este projeto tem como objetivo ajudar estudantes a organizar suas matérias e facilitar a rotina de estudos, oferecendo uma maneira simples e prática de visualizar os conteúdos que precisam estudar.

Objetivo
Desenvolver uma aplicação que auxilie os estudantes na organização dos estudos, contribuindo para um melhor planejamento e aproveitamento do tempo dedicado à aprendizagem.

Tecnologias utilizadas
-Python
-FastAPI
-Pytest
